# AgeCare v1.5 UI and discharge update

- Redesigned Notifications with the same 26 px rounded white cards used across Residents and Alerts, including a slim severity/type line on the left.
- Redesigned Messages with rounded white conversation cards, a subtle unread indicator line, cleaner metadata and responsive list/grid presentation.
- Simplified Login to a focused AgeCare staff sign-in card and shortened prototype/reset wording.
- Simplified Menu by removing helper paragraphs and tile subtitles while keeping Schedule, Notifications, Privacy, Security, Help and Logout functional.
- Added a subtle **Discharge** action inside Resident details. Confirming discharge removes the resident from active care and also clears linked tasks and alerts to avoid orphan records.
- Alerts and Notifications now listen to application state so discharged residents disappear immediately when returning from their profile.
- Task details close automatically if the linked resident is discharged, keeping navigation consistent.
- Standardised card corners and shadows for a softer, more professional mobile interface.

# AgeCare v1.3 UI refinement

- Removed the **Add** button from the top-right of the Residents page. New admissions remain available from the main bottom/side navigation.
- Resident cards now use a clean white surface. Status is communicated by the slim coloured left edge and an outlined status label only.
- Alert and notification cards also use clean white surfaces with a coloured left edge and concise outlined severity/type labels.
- Removed the **Emergency services contact** and **Shift partner alert** quick-action cards from the Home dashboard.
- Reduced unnecessary wording in resident results and notification labels for a cleaner, easier-to-scan interface.
- Preserved responsive layouts, linked resident/task/alert navigation, search, filters, admission workflow and login/logout behaviour.

# Change Log

## v1.2.0

- Removed the large **Care dashboard** welcome banner from the Home screen so the search and operational information appear sooner.
- Added patient-status colour treatment to Resident cards: high priority = red, review = orange, stable = green, low priority = cyan. Status is also written as text so meaning is not communicated by colour alone.
- Redesigned Notifications with colour-coded alert/task types, visible type labels, semantic icons, subtle tinted cards and left accent bars.
- Kept every notification linked to the relevant resident profile or task details page.
- Maintained responsive layouts and accessible, high-contrast labels in line with the assessment usability rubric.


## v1.4 — Resident and Alert UI refinement
- Simplified the Residents page by removing the repeated greeting header, resident count row and long helper wording.
- Shortened search and filter labels for faster scanning.
- Redesigned resident cards with iPhone-style 26 px rounded corners, cleaner metadata and softer shadows.
- Kept status colour only as a subtle translucent left rail and compact status chip; the card surface remains white.
- Removed extra resident-card labels to reduce visual clutter.
- Simplified Alert cards to the alert title, resident, time and a compact type label.
- Kept alert cards white with restrained severity colour on the side rail/icon only.
- Increased global corner radii slightly and softened the app background for a more polished, consistent mobile UI.
